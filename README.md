Blinkit Sales Analysis Dashboard

Project Overview

This project analyzes Blinkit sales data to understand sales performance, customer preferences, product categories, and outlet performance. I used Power BI to build an interactive dashboard and identify key business insights from the data.

Tools Used

- Power BI
- Power Query
- DAX
- Data Cleaning and Data Visualization

Dashboard Features

- KPI Cards: Total Sales, Average Sales, Number of Items, and Average Rating.
- Interactive Filters: Outlet Size, Outlet Location, Outlet Type, and Item Type.
- Visualizations: Sales by Item Type, Fat Content, Outlet Establishment Year, Outlet Size, and Outlet Location.
- Outlet Analysis: Compare the performance of different outlet types and locations.

Key Insights

- The total sales were approximately $1.2 million.
- Fruits and Vegetables and Snack Foods were among the leading product categories.
- Tier 3 locations contributed significantly to overall sales.
- Supermarket Type 1 outlets showed strong sales performance.
- The dashboard helps compare sales across product categories and outlet characteristics.

Skills Demonstrated

- Data Cleaning using Power Query
- Data Modeling and DAX
- KPI Development
- Interactive Dashboard Creation
- Data Analysis and Visualization
- Business Insights and Reporting

Project Outcome

This project helped me understand how to transform raw sales data into an interactive dashboard and use data-driven insights to evaluate business performance.
